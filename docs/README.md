# SSL Business Platform Website and App Prototype Docs

Use these markdown files with the 3 supplied screenshots in the same `/docs` folder.

## Goal
Build a Google Workspace-inspired Next.js prototype for SSL Wireless's unified business services platform. The experience should feel calm, spacious, trustworthy, and enterprise-grade, while using SSL Wireless, SSLCOMMERZ, SMS, and virtual recharge content.

## Important legal and design boundary
Do not copy Google Workspace assets, logos, illustrations, product icons, brand colors as exact brand identity, or text. The goal is to match the design language, layout rhythm, spacing, interaction style, and page composition using SSL Wireless branding and original assets.
